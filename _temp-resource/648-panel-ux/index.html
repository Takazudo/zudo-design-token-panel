zdtp — 10 improvement prototypes

Standalone HTML, no build. Each page is a fake host page + a shell that mirrors the real panel chrome (same tokens as panel-tokens.css), plus one new idea. The card at the bottom-left of every page explains what to try. Effort tags are a rough guess for landing it in packages/zdtp.

01small
Token search + ⌘K palette

Header filter (/) narrows the current tab and shows "also in Spacing 2" chips; ⌘K fuzzy-jumps to any token in any tab and runs actions.

Why: the Color tab alone has ~30 rows; finding one is scrolling.

 02small
Changed-state visibility + per-row revert

Accent bar, bright input, ghost "default → now", ↺ on each changed row; count badges on tabs; "Changed only" filter; footer Copy diff / Revert all.

Why: today nothing tells you what you tweaked until Export.

 03discarded
Scrub-to-adjust numbers

Drag a label sideways (Shift ×10, Alt fine), ↑/↓ in the input, or a hairline slider under the value with a default tick. Host page bound live.

Why: numbers are the main thing edited, and every edit is select → type → tab.

Discarded: a slider needs a min/max per token. Fine for font-size, unworkable for width-like tokens — it was tried before and the range config was the cost. Kept for reference only.

 04bmedium
Type specimen with your own text (revised 04)

Font tab as a specimen: your text (Latin / 日本語 / custom, persisted) at every scale token in the host's real font, paragraph specimens per line-height with leading guides, and a "Render on page" mode that moves the specimen into the host document.

Why: the in-row "Aa" glyph breaks the grid at 60px and says nothing about Japanese text. Spacing/radius/transition glyphs from 04 stay small and survive.

 04small
Live value glyphs (spacing / radius / transition part survives)

Aa at real size, line-height lines, spacing bar, radius box, a dot animating at the transition duration, contrast pill on colors, ramp-shape strip per spacing tier.

Why: "1.375rem" means nothing until it is on the page.

 05medium
Undo / redo history + A/B snapshots

History rail with time-travel, ⌘Z / ⌘⇧Z, two named snapshots flipped with \ to compare directions on the live page.

Why: one bad drag and the previous value is gone.

 06medium
Dock modes + ghost-when-idle

Float / dock-right / dock-bottom / mini-pill (Alt+1…4); docked modes reflow the host instead of covering it; the panel fades while the pointer is on the page.

Why: a 900×560 floating window hides the layout you're tuning.

 07medium
Resolution chain + "used by"

🔗 expands token → ramp step → oklch → hex, element count on page, dependents, ramp siblings; on a ramp step: "referenced by 3 tokens, 45 elements change".

Why: ref tiers exist in the data model but the UI shows only a select.

 08medium
Apply preview — file diff before writing

Files, +/- lines inside the scanned block, checkbox per token, loud row for unrouted tokens, "in sync with disk" dot in the header.

Why: Apply writes first and reports after.

 09small
Bulk scale a ramp

Row checkboxes, tier select-all, ×0.9 / ×1.1 on the heading, action bar with multiply / add / round / set, per-row old → new preview and a ramp silhouette.

Why: "10% tighter" is one intent but seven edits, and ratios drift.

 10larger
Inspect an element → its tokens

Crosshair (I), click a page element, the panel shows only the tokens it reads grouped by CSS property plus inherited ones, live-editable. Resolves rules for real.

Why: the eye icon answers token → elements; nothing answers element → tokens.

Two demos in this repository run the workspace build of `@takazudo/zdtp` on ZFB. Each page shows build provenance from the git tag position and the source SHA. Apply is omitted on the public sites because writing source files needs the local sidecar.

## Wind

[https://zdtp-demo-zudowind.zudolab.dev/](https://zdtp-demo-zudowind.zudolab.dev/) — zudo-wind utilities backed by authored custom properties. Card padding, radius, surface, and ink use `p-card`, `rounded-card`, `bg-surface`, and `text-ink`.

Source: [`demos/zudowind`](https://github.com/Takazudo/zudo-design-token-panel/tree/main/demos/zudowind).

Interactive pages accept [`?manifest=zudo-doc`](https://zdtp-demo-zudowind.zudolab.dev/?manifest=zudo-doc) to load the vendored zudo-doc `PanelConfig`. English and Japanese prose pages exercise the same tokens in longer content.

## CSS Modules

[https://zdtp-demo-cssmodules.zudolab.dev/](https://zdtp-demo-cssmodules.zudolab.dev/) — the same authored properties, with `wind: false` and component `*.module.css` files.

Source: [`demos/cssmodules`](https://github.com/Takazudo/zudo-design-token-panel/tree/main/demos/cssmodules).

## Static token dashboard

[https://zdtp-demo-zudowind.zudolab.dev/dashboard/](https://zdtp-demo-zudowind.zudolab.dev/dashboard/) lists the Wind demo manifest with `TokenDashboard`. It is a page of that demo, not a separate application. Saved panel edits do not change the static inventory. See the [static token dashboard recipe](../recipes/static-token-dashboard.mdx).

## Documentation site

This site, [https://zdtp.zudolab.dev/](https://zdtp.zudolab.dev/), installs the published `@takazudo/zdtp` release named in `doc/package.json`. The two demos above follow the workspace package and can be ahead of that release. The provenance line on each demo says which one you are looking at.

Local development:

```sh
pnpm demo:wind
pnpm demo:cssmodules
```

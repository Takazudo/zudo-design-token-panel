このリポジトリの二つのデモは、ZFB 上で `@takazudo/zdtp` のワークスペースビルドを動かします。各ページは git タグの位置とソース SHA から作った出自を表示します。公開サイトでは Apply を出していません。ソースへ書き戻すにはローカルのサイドカーが必要です。

## Wind

[https://zdtp-demo-zudowind.zudolab.dev/](https://zdtp-demo-zudowind.zudolab.dev/) — 自分で書いたカスタムプロパティを zudo-wind のユーティリティが参照します。カードの余白、角丸、面、文字色は `p-card`、`rounded-card`、`bg-surface`、`text-ink` です。

ソースは [`demos/zudowind`](https://github.com/Takazudo/zudo-design-token-panel/tree/main/demos/zudowind) です。

対話ページでは [`?manifest=zudo-doc`](https://zdtp-demo-zudowind.zudolab.dev/?manifest=zudo-doc) を付けると、取り込んだ zudo-doc の `PanelConfig` を読みます。英語と日本語の prose ページは、同じトークンを長い文章で確認します。

## CSS Modules

[https://zdtp-demo-cssmodules.zudolab.dev/](https://zdtp-demo-cssmodules.zudolab.dev/) — 同じカスタムプロパティを、`wind: false` とコンポーネントの `*.module.css` で使います。

ソースは [`demos/cssmodules`](https://github.com/Takazudo/zudo-design-token-panel/tree/main/demos/cssmodules) です。

## 静的トークンダッシュボード

[https://zdtp-demo-zudowind.zudolab.dev/dashboard/](https://zdtp-demo-zudowind.zudolab.dev/dashboard/) は Wind デモのマニフェストを `TokenDashboard` で一覧します。別のアプリケーションではなく、そのデモの一ページです。保存したパネルの編集は、この静的な一覧を変えません。[静的トークンダッシュボードのレシピ](../recipes/static-token-dashboard.mdx)を参照してください。

## ドキュメントサイト

このサイト [https://zdtp.zudolab.dev/](https://zdtp.zudolab.dev/) は、`doc/package.json` に書いた公開版の `@takazudo/zdtp` を使います。上の二つのデモはワークスペースのパッケージに追従するため、公開版より新しいことがあります。どちらかは、各デモの出自表示で分かります。

ローカルでは次を実行します。

```sh
pnpm demo:wind
pnpm demo:cssmodules
```

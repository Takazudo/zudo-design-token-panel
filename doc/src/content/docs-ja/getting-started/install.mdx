`@takazudo/zdtp` は ZFB 向けのライブなデザイントークンパネルです。`@takazudo/zfb` と `@takazudo/zfb-runtime` と一緒に入れます。`configurePanel({...})` はパネルを独自の zudo-react ツリーとしてマウントします。

このページではパッケージ自体のインストールを説明します。レイアウトへの組み込みについては[クイックスタート](./quickstart.mdx)を参照してください。

## パッケージをインストールする

プロジェクトのパッケージマネージャーに合うコマンドを選んでください。パネルは zfb の zudo-react ランタイムを同梱しているため、命令型 API を使うホストではパネルだけを指定し、ホストの JSX ランタイムは React や zudo-react のまま使えます。

### pnpm

```sh
pnpm add @takazudo/zdtp
```

### npm

```sh
npm install @takazudo/zdtp
```

### yarn

```sh
yarn add @takazudo/zdtp
```

### bun

```sh
bun add @takazudo/zdtp
```

<Note title="パネルはレンダラーを同梱しています">
  0.9.0 からパネルは zfb の zudo-react ランタイムを同梱してレンダリングし、`preact` は `@takazudo/zdtp` の依存関係ではなくなりました。例外は静的な `@takazudo/zdtp/dashboard` エントリーで、ホストの zudo-react でレンダリングするため、利用するホストは `@takazudo/zfb`（任意の peer、`^5.1.2 || ^6.0.0`）をインストールします。0.8.x から更新するホストで、ZDTP 経由で入る Preact を自身のコードに使っていた場合は、自身の依存関係に `preact` を追加してください。パネルのツリーは他のレンダラーと分離します。
</Note>

## インストールを確認する

インストール後、パッケージはプロジェクトルートから確認できる次の 3 種類を公開します。

- ライブラリエントリ — `@takazudo/zdtp`（`configurePanel` とパネル本体）。
- ダッシュボードエントリ — 静的な `TokenDashboard` 用の `@takazudo/zdtp/dashboard`。
- CLI bin — ローカルの Apply パイプラインで使う `zdtp-server`。

プロジェクト内の PATH から bin を実行できるか、次のコマンドで確認できます。

```sh
pnpm exec zdtp-server --help
# or
npx zdtp-server --help
```

ヘルプが表示されれば、パッケージは正しくインストールされています。

## apply パイプライン用 bin

パッケージには `zdtp-server` という実行ファイルが含まれます。開発サーバーと並行して動作し、ループバックポートで待ち受け、パネルで **Apply** をクリックしたときにトークン CSS ファイルを書き換えます。

<Tip title="今は省略できます">
  bin は任意です。bin がなくても、エクスポート／インポートモードでパネルの全機能を利用できます。パネル上の変更をディスクへ反映したくなった時点で組み込んでください。
</Tip>

完全な CLI リファレンスは[専用ページ](../reference/cli-zdtp-server.mdx)にあります。概要は次のとおりです。

```sh
npx zdtp-server \
  --routing ./panel-routing.json \
  --write-root ./tokens \
  --allow-origin http://localhost:5173
```

## ランタイム依存関係の境界

ZDTP は `@tailwindcss/browser`、`tailwind-merge`、`culori` を通常の依存関係としてインストールします。Tailwind コンパイラーは DOM Tweaker の遅延有効化境界の内側にあり、通常のパネルを開いても読み込み・実行されません。Tailwind を一切インストールしない構成ではありません。別パッケージや任意のエントリへの分離は、互換性を別途検討する変更です。`optionalDependencies` に移しても既定ではインストールされます。

ZFB では `getScope().onActivate()` 内でパネルを import し、アイランドの破棄時に読み込み待ちをキャンセルします。そのライフサイクル内で返されたハンドルを設定・破棄してください。パネルのノードをホストの zudo-react ツリーに渡してはいけません。

<Info>
  パネルの CSS は自己完結しています。パネル専用の `--tokentweak-*` 名前空間にまとめたスタイルシートが同梱されています。パネルを利用するプロジェクトに **Tailwind は不要です**。
</Info>

<Info title="スタイルの import は不要です">
  パネルは実行時に自身のスタイルシートを注入します。初めてパネルを開くと、バンドル済み CSS を持つ `<style>` 要素を追加します。CSS を利用側で import する必要はありません。`@takazudo/zdtp/styles`（および `/styles.css`）の export も引き続きバンドル済みスタイルシートへ解決されるため、独自のスタイルシートパイプラインへ取り込みたい場合は利用できますが、現在は任意です。
</Info>

Released: 2026-09-08

### 機能

- 静的ダッシュボード用に宣言されたトークンの既定値をモデル化 (422643b)
- 静的な Preact トークンダッシュボードを公開 (5b6c0f8)
- 静的トークンダッシュボードのデモとドキュメントを追加 (2edd98b)
- ルーラー、パレットストリップ、幅広い文字見本を追加 (7cdf01f)

### バグ修正

- 従来のパレット参照と併存するセマンティック値のリテラルを保持 (b813c8a)

### その他の変更

- 独立したダッシュボード CSS の配信をテスト (a00541a)
- pack したダッシュボードの SSR と公開 CSS の利用を検証 (6cd8157)
- 静的ダッシュボードのレイアウト寸法をブラウザーで検証 (e07d69e)
- ダッシュボードのブラウザーテストのファイルモードを統一 (0ec8217)
- ルーラー、カラーパレット、文章見本の使い方を説明 (859d3a4)
- pack したダッシュボードの一覧表示と previewText を検証 (7ebf4cf)
- 隔離した外部アプリからのダッシュボードパッケージ利用を検証 (fdb3906)
- モジュール形式による違いを考慮して Preact パッケージの同一性を比較 (bb280ee)
- 静的ブラウザーテストの読み込みとポーリングを修正 (3fe6203)

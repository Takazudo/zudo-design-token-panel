Released: 2026-09-08

### 破壊的変更

- 予約された palette タブの設定を検証 (73e70f9)。`palette` タブでは `colorExtras`、空の tier、色以外の項目を含む tier、不統一な CSS 変数名を拒否するようになりました。Astro ホストの設定検証にも影響します。**移行方法**: `palette` タブから `colorExtras` を削除し、各 tier に色の項目を1つ以上設定してください。CSS 変数名は、共通の接頭辞と連続した番号、または共通の接頭辞と重複しない名前に統一してください。異なる型が混在する汎用 tier は別名のタブに移し、`referencesRamps` のタブ参照も更新してください。

### 機能

- minimal デモにグループ化したパレットとセマンティックカラーの例を追加 (5dcbe12)
- playground でグループ化した OKLCH パレットとセマンティックカラーを使用 (42c7c86)

### バグ修正

- モード別カラーの適用時にホストの color-scheme を保持 (90c30c6)
- 各インスタンスの値を使って書体見本を描画 (7d18952)
- 生成された型宣言のモジュール指定子を正規化 (8f858c0)
- 公開エントリーポイントからパネル設定の検証関数を利用可能に (5335713)

### その他の変更

- グループ化したパレットとモード別セマンティックカラーの解説を更新 (3d1d114)
- playground のカラーをグループ化したセマンティックランプに再構成 (2076abe)
- Chromium で書体見本のインスタンス間の独立性を検証 (6ff7ed6)
- TypeScript の各モジュール解決モードでパッケージ内の型宣言を検証 (f1e5e21)

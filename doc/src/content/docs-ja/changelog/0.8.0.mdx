### 破壊的変更

- モードに応じたトークン領域をダッシュボードに実装 (bd8fb6b)。モード依存の行が独立した行より先に、別々の領域で表示されます。独立した行の見本は `chrome`、モード依存の行の見本は `mode` に従います。**移行方法**: 独自の DOM/CSS 連携では `.zdtp-dashboard__region` を対象にしてください。全体をダークにする場合は `mode="dark"` と `chrome="dark"` を指定し、一覧を分ける場合は `include="mode-dependent"` と `include="mode-independent"` のインスタンスを組み合わせてください。
- テーマ入力からダッシュボードの外観色を導出 (495af9f)。外側のルートは透明になり、ヘッダーと各領域に導出色が適用されます。**移行方法**: 周囲のページ背景はラッパーに指定し、従来の固定パレットに依存する代わりに、継承される 4 つの入力 `--zdtp-dashboard-light-bg`、`--zdtp-dashboard-light-fg`、`--zdtp-dashboard-dark-bg`、`--zdtp-dashboard-dark-fg` を調整してください。
- 行単位のモード依存モデルを実装 (d570b9b)。既存のトップレベル `light-dark()` の既定値は、ライト／ダークのスナップショットでは選択された側を表示・出力し、空のグループは省略されます。**移行方法**: ブラウザーが選ぶペアを宣言に残す場合は `mode="host"` を使用してください。絞り込み前の宣言順や空のグループが必要な場合は、元のマニフェストを参照してください。内部モデルヘルパーの位置引数によるモード指定は引き続き利用できます。
- インポートモーダルに範囲選択フローを追加 (a8223ba)。JSON の解析後に Load が利用可能になります。**移行方法**: UI 自動操作では **Analyze** を実行するか **Import scope** の表示を待ち、タブとオプションを選んでから **Load** を実行してください。

### 機能

- モード依存トークンの共通ヘルパーを追加 (28cceb8)
- トークンのインポート解析、範囲指定、モード変換を追加 (e2ea25a)
- パネルのライフサイクル全体でマニフェストのカラーモードを適用 (08bfb52)
- マニフェストのモード行の表示とシリアライズに対応 (2b501bf)

モードペアはパネルでは表示専用です。モード別の編集は [#953](https://github.com/Takazudo/zudo-design-token-panel/issues/953) で追跡しています。差分エクスポートは引き続き `item.default` と比較します。完全なエクスポートには `includeDefaults: true` を使用してください。

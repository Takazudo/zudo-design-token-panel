Released: 2026-09-09

### 破壊的変更

- feat(dashboard): クローム（外観）テーマをスペシメンのモードから分離しました (84d4d8a)。`TokenDashboard` はクロームの外観を `mode` から導出しなくなりました。従来は `mode="dark"` を渡すとインベントリのスコープに `color-scheme: dark` が付与されていましたが、今後は `.zdtp-dashboard__specimen` にのみ付与され、クロームは既定でライトになります。**移行方法**: 従来のダーククロームを維持するには `mode="dark"` と併せて新しい `chrome="dark"` を渡してください。ホストの実効カラースキームを継承する場合は `chrome="host"` を指定します。

- ホストのコンテキストで CSS の色式を解決するようにしました ([#919](https://github.com/Takazudo/zudo-design-token-panel/issues/919)) (30dbabc)
- 色式を編集する前に明示的な変換を必須にしました (ffad163)

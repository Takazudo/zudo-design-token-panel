Released: 2026-09-06

`@takazudo/zdtp/constants` から、パネルを読み込まずに `DEFAULT_STORAGE_PREFIX`、`DEFAULT_TOGGLE_EVENT`、`resolveToggleEventName`、`EAGER_LOAD_GATE_KEY_SUFFIXES`、`EAGER_LOAD_GATE_STATE_FAMILY` を利用できるようになりました。遅延読み込みを行うホストで、トグルイベントの規則と先行読み込みの判定メタデータを共有できます。状態キーは名前の一致だけでなく、文書化された内容の確認も必要です。ストレージキーの説明も訂正しました。位置、サイズ、密度、および3種類のハイライト用キーは、公開済みの 0.4.14 にすでに存在していました。

### 機能

- feat(zdtp): 独立した constants エントリーポイントを公開 (11ff48b)
- feat: 先行読み込みの判定条件をメタデータとして公開し、実際の動作との一致をテスト (0a2b610)

### バグ修正

- fix: ドック操作を常に表示し、メニューの状態を実際の CSS 表示に同期 (dae7dcc)
- fix(zdtp): 変更済みトークン行のラベルに読みやすい幅を確保 (97ede7f)

Released: 2026-10-26

### 機能

- feat: 独立したダッシュボードのクライアントマウント API を追加。Preact レンダラーを持たないホスト向けに、新しいサブパス `@takazudo/zdtp/dashboard/client` から `mountTokenDashboard(host, props)` と、何度呼んでも安全な `dispose()` ハンドルを提供 (b4a9f82)

### バグ修正

- fix: 復帰処理をまたいでもパネル内部の Close を優先するように修正。× ボタンや Escape で閉じた意図を、250 ms の再オープン復帰タイマーがパネルを再マウントする前に保存 ([#1049](https://github.com/Takazudo/zudo-design-token-panel/pull/1049)) (8e12a70)
- fix: ドキュメント側のパネルトグルを分離し、キューに積んだ再生を描画後まで遅延 (74b21ee)
- fix: ネイティブなドキュメント遷移をまたいで早期のパネルクリックを保持 (c816aed)
- fix: ドキュメント開発サーバーの起動を一貫した eager モードに統一 (1656d84)
- fix: PR プレビュー全体で no-preview ラベルを使い、レシピの固定バージョン説明を明確化 (5b8fef0)
- fix(ci): zudo-doc ドリフトジョブを上流が宣言する Node の範囲で実行 (58a70ce)
- fix(docs): issue 1002 のホスト契約とパック検証を整合 (99274f1)

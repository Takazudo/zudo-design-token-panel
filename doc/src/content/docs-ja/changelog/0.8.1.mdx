Released: 2026-09-21

### 機能

- マニフェストの `modes` 行を、ライト／ダークそれぞれ独立して編集できるようになりました。表示専用のチップ 2 つではなく、ライトとダークの `ColorField` が並びます。一方を編集すると、触れていない側をそのまま保ったままペア全体が `light-dark(light, dark)` としてコミットされるため、書式が混在したペアでも元の記法が維持されます。Reset でマニフェストのペアに戻ります。対象は汎用タブと Palette の両ビューで、Color タブのパレットスロットに宣言した `modes` はこれまでどおり表示専用です (a2a03fd, b87d2f6, 9368067, e32390a)
- 保存済みのオーバーライドが `item.default` と同じ値であっても、マニフェストのペアより優先されるようになりました。読み込んだ state が元の値に戻らず、そのまま往復します (e32390a)

### バグ修正

- Palette Check ビューで `readonly` のマニフェスト `modes` 行を表示専用に戻しました。他のすべての画面では正しくチップ 2 つのままだったのに対し、この画面だけ編集可能なカラーフィールドが表示されていました (6302328)

### その他の変更

- トークンマニフェストリファレンスの `modes` の節を、左右それぞれの編集、`light-dark()` としてのコミット、Reset、Color タブのパレットスロットの例外、`readonly` の扱いを説明する内容に、日英とも更新しました (27bb35e)
- ドキュメントサイトのホームページを zudo-doc の `home.wide` サイトマップレイアウトに切り替えました (e0fba99)
- per-mode エディターのテストを追加しました。算出されたライト／ダークのペアを確認するブラウザテスト、hostile-host 分離のケース、モードペアのコミット経路のユニットテストです (bbe97a6, 6168338, 682986b)

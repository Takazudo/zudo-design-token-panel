Install `@takazudo/zdtp`, configure its token manifest, and compare supported host-framework integrations.

:::note[Documentation and the embedded panel]
These pages describe the latest code on the panel's `main` branch. The live panel embedded in this site uses a pinned published release, so newly documented options may not be supported yet by the panel you see here. Setting an unsupported option is silently ignored, without an error or warning.
:::

`@takazudo/zdtp` をインストールし、トークンマニフェストを設定して、対応するホストフレームワークでの組み込み方法を比較します。

:::note[ドキュメントとサイト内のパネルの違い]
このドキュメントは、パネルの `main` ブランチの最新コードをもとに書かれています。一方、このサイトに組み込まれているパネルは公開済みのリリースにバージョンを固定しているため、新しく記載されたオプションにはまだ対応していない場合があります。未対応のオプションを設定しても、エラーや警告は出ず、その設定は無視されます。
:::
